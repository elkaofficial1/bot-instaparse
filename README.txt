Instagram Reels Checker — тестовый прототип

1. Установить Python 3.10+.
2. В папке проекта выполнить:
   python -m pip install -r requirements.txt
   python -m playwright install chromium

3. Запуск:
   python instagram_reels_checker.py "/путь/к/аккаунты-2026-11-09.xls" --limit 10

   --limit 10 проверит только первые 10 найденных аккаунтов.
   Убери --limit для всей базы.

4. Откроется Chromium. Войди в Instagram вручную и нажми Enter в терминале.
5. Итоговый файл instagram_checked.xlsx:
   - лист «Оставить» — строки исходной базы, прошедшие фильтр;
   - лист «Все проверки» — дата, ссылка, статус и причина.

Ограничения тестовой версии:
- Instagram может ограничивать автоматические переходы и показывать неполные данные.
- Проверка закреплённых Reels сделана по доступным подписям интерфейса и пока экспериментальная.
- Если дату достоверно получить не удалось, аккаунт не попадает в «Оставить».
- Пароль программа не запрашивает и не сохраняет.
